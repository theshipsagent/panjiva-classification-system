# 04_DEVELOPMENT - Development Files

This folder contains experimental, test, and deprecated files not part of the production pipeline.

## Folder Structure

- **04.01_experiments/** - Experimental scripts and prototypes
  - New feature development
  - Algorithm prototypes
  - POC implementations

- **04.02_tests/** - Test scripts and sample datasets
  - Unit tests
  - Integration tests
  - Small test datasets

- **04.03_deprecated/** - Old versions of production scripts
  - Historical script versions (v1.0.0, v1.1.0, etc.)
  - Replaced functionality
  - Kept for reference and rollback if needed

## Usage

Files in this folder are NOT part of the production pipeline.

For production scripts, see 02_SCRIPTS/.

Old versions are kept here for auditing and potential rollback scenarios.
