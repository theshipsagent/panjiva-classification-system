### Contains_All Strategy Usage (Safety First)

The following entities use `Contains_All` to prevent false positives from generic words:

| Entity | Keywords | Rationale |
|--------|----------|-----------|
| **GM-001** | GENERAL MOTORS | Avoid matching "GENERAL" alone |
| **KIA-001** | KIA MOTORS | Avoid matching "KIA" alone |
| **DOW-001** | DOW CHEMICAL | Avoid matching "DOW" alone |
| **SK-ENERGY-001** | SK ENERGY | Avoid matching "SK" alone |
| **TITAN-001** | TITAN CEMENT | Avoid matching Titan America or other Titan entities |
| **MARTIN-001** | MARTIN MARIETTA | Avoid Martin Gas, Martin Wine, etc. |
| **HOUSTON-CEMENT-001** | HOUSTON CEMENT | Avoid Houston Refining or other Houston entities |
| **ASH-GROVE-001** | ASH GROVE | Multi-token safety |
| **HYUNDAI-STEEL-001** | HYUNDAI STEEL | Distinguish from Hyundai Motor |

## Migration Guide

### For Existing v1.1.0 Users

1. **Backward Compatible**: v1.2.0 includes all v1.1.0 entities unchanged
2. **No Breaking Changes**: Same CSV schema, same column names
3. **Drop-in Replacement**: Update file path in harmonization scripts
4. **Incremental Testing**: Test on 2023 data first, then expand to 2024-2025

### Testing Workflow

