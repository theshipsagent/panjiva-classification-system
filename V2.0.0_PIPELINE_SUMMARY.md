## Lock System

### How Locks Work

Locks control which taxonomy levels can be refined by later phases:

| Lock Column | What It Locks |
|-------------|---------------|
| `Group_Locked = TRUE` | Group cannot be changed |
| `Commodity_Locked = TRUE` | Group + Commodity locked |
| `Cargo_Locked = TRUE` | Group + Commodity + Cargo locked |
| `Cargo_Detail_Locked = TRUE` | All 4 levels locked (final) |

### Example Flow

**Phase 1 (Carrier Lock):**
```
Rule: Carrier = "WALLENIUS" → Group = "Ro/Ro"
Sets: Lock_Group = TRUE
Allows: Later phases can refine Commodity/Cargo/Cargo Detail
```

**Phase 6 (Refinement):**
```
Rule: Vessel_Type = "RoRo" + HS6 = "870323" → Commodity = "Autos"
Checks: Lock_Commodity = FALSE (can apply)
Sets: Commodity = "Autos", Lock_Commodity = TRUE
```

**Phase 10 (Final):**
```
Rule: Keywords = "TESLA MODEL 3" → Cargo_Detail = "Tesla Model 3"
Sets: All locks = TRUE (final classification)
```

## Troubleshooting

### Issue: "Column not found: Vessel_Type_Simple"
**Cause:** Using v1.0.0 data with v2.0.0 script
**Fix:** Upgrade data file to v2.0.0 first

### Issue: "0% vessel enrichment"
**Cause:** Forgot to run enrichment step after upgrade
**Fix:** Run `enrich_vessel_data_v2.0.0.py`

### Issue: "Phase 1 shows 0% matches"
**Cause:** Vessel enrichment didn't work
**Fix:** Check ship registry exists, verify vessel names match
