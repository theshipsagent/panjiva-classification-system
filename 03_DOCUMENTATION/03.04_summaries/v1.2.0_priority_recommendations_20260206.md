## Risk Mitigation

### Risk 1: Name Variants Not Captured
**Solution:** Use fuzzy matching patterns
- Include common abbreviations: "Corp", "Corporation", "Co.", "Company"
- Case-insensitive matching
- Remove punctuation variations: "St. Mary's" vs "St Marys" vs "Saint Mary's"

### Risk 2: False Positives
**Solution:** Use more specific match patterns
- Avoid generic names: "Trading", "Corporation", "International"
- Require 2+ unique tokens: "Gunvor" + "Group" or "Gunvor" + "Trading"
- Add exclusion list for common false matches

### Risk 3: Coverage Gains Lower Than Expected
**Solution:** Monitor and iterate
- If coverage < 55%, add Tier 4 entities (500K-1M tons)
- Extend to top 60-80 entities
- Focus on industries with low current coverage

### Risk 4: Entity Name Ambiguity
**Solution:** Add context matching
- Combine entity name + HS code category
- Combine entity name + origin country
- Use cargo type as secondary validation

## Appendix: Analysis Methodology

**Data Source:** panjiva_imports_2024_HARMONIZED_v1.1.0.csv (449,233 records)

**Analysis Steps:**
1. Identified unmatched records (Match_Type = None or NaN)
2. Aggregated by normalized party name
3. Calculated total tonnage and record count per entity
4. Identified cross-field entities (same entity in 2+ fields)
5. Categorized by industry using keyword patterns
6. Ranked by priority score (tonnage + multi-field bonus)
7. Filtered by 500K ton minimum threshold

**Industry Categorization:**
- Oil/Gas: crude, petroleum, diesel, fuel, energy company names
- Steel: steel, iron, coil, slab, steel company names
- Cement/Aggregates: cement, clinker, aggregate, concrete
- Chemicals: chemical, polymer, plastic, resin, chemical company names
- Mining/Minerals: mining, coal, ore, mineral, aggregate, mining company names
- Logistics/Trading: logistics, shipping, trading, freight, trading company names
- Agriculture: grain, wheat, corn, fertilizer, ag company names
- Forest Products: lumber, wood, pulp, paper, timber
- Food/Beverage: food, juice, sugar, beverage company names
- Utilities: utility, power, electric, utility company names
- Other: Everything else

**Priority Scoring:**
- Base score: Total tonnage
- Multi-field bonus: +1M tons per additional field
- Ranking: Sort by priority score descending
