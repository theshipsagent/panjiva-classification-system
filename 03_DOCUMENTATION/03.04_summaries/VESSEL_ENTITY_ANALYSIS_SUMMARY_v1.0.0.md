# Vessel-Entity Relationship Analysis Summary
## Version 1.0.0 | 2026-02-05

**Analysis of 449,233 harmonized 2024 import records across 21 entities**

---

## Executive Summary

This analysis reveals strong carrier preferences and vessel specialization patterns across harmonized maritime entities. Key findings include:

- **267 recurring vessel-entity relationships** (3+ visits per year)
- **813 highly specialized carriers** (90%+ tonnage in single vessel type)
- **52.1% of tonnage moves via tankers** (predominantly Aframax class)
- **Strong carrier loyalty**: Irving Oil (84% with Vroon), Saudi Refining (99% with AET)

## Data Quality Notes

### Strengths
- **88-90% vessel enrichment** from ship registry (IMO-based matching)
- **21 harmonized entities** with clean entity IDs
- **449,233 records** representing 724M tons

### Limitations
1. **Tanker specialization**: Registry lacks crude/product/chemical distinctions
2. **"Unknown" vessel types**: 14.1% of tonnage (102M tons) not classified
3. **Shipment count anomalies**: Some major carriers show "0" shipments (data artifact)
4. **General cargo misclassification**: 43M tons (6%) classified as "General Cargo" likely includes breakbulk steel

### Recommendations for Future Analysis
1. **Enhance ship registry** with detailed tanker specialization codes
2. **Add cargo-vessel alignment validation** (crude oil should only move via crude tankers)
3. **Investigate "0 shipment" anomalies** in carrier relationship data
4. **Cross-reference with USACE data** to validate vessel types for "Unknown" category

## Appendix: Analysis Types in Output File

The CSV contains 7 analysis types:

1. **Entity_Vessel_Type**: Entity tonnage by vessel type (% distribution)
2. **Entity_Carrier**: Entity tonnage by carrier (preferred carriers)
3. **Entity_Tanker_Specialization**: Entity tonnage across tanker subtypes
4. **Vessel_Entity_Fleet_Pattern**: Recurring vessel-entity relationships (visit frequency)
5. **Entity_Vessel_Size**: Entity tonnage by vessel size class (Aframax, VLCC, etc.)
6. **Carrier_Vessel_Type_Specialization**: Carrier specialization in vessel types
7. **Entity_Carrier_Vessel_Type_Triangle**: Combined entity-carrier-vessel relationships
