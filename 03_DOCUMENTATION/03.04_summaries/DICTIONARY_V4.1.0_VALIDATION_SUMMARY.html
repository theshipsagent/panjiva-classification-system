Dictionary v4.1.0 Changes

Fix #1: Remove BLK from NOISE-LIGHT-LIQUID Filter

Line 8: NOISE-LIGHT-LIQUID package type

Change: LBK|BLK → LBK

Impact: Stops excluding dry bulk commodities (iron ore, coal, grain) under 75 tons

Recovery: ~4.5M tons iron ore + additional dry bulk

Fix #2: Increase Crude Oil Max Tonnage

Lines 57, 141: CRUDE-OIL, CRUDE-OIL-P5

Change: Max_Tons 175,000 → 500,000

Impact: Captures VLCC (Very Large Crude Carrier) shipments up to 320K tons

Recovery: ~13.3M tons crude oil

Fix #3: Add Missing Crude Oil Keywords

Lines 57, 141: CRUDE-OIL, CRUDE-OIL-P5

Added Keywords:

  • Brazilian grades: tupi|bauna|frade
  • Guyanese grades: liza|payara|utapate
  • Venezuelan grades: merey
  • Colombian grades: castilla
  • Other: amenam|bonny light|boscan|hebron|mizton|ebok|mero

Recovery: Additional crude oil tonnage from non-US sources

Fix #4: Add Sugar Keyword Variations

Lines 84, 168: SUGAR, SUGAR-P5

Change: sugar → sugar|cane sugar|raw sugar|refined sugar|sugarcane

Impact: Captures descriptive sugar terminology

Recovery: ~859K tons sugar

Fix #5: Lower Steel Slabs Min Tonnage

Line 21: STEEL-SLABS

Change: Min_Tons 2,000 → 1,000

Impact: Captures smaller slab shipments (1K-2K ton range)

Recovery: ~740K tons steel slabs
