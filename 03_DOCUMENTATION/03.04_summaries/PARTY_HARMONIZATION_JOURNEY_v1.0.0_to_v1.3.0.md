## Key Learnings & Patterns

### 1. Tonnage-Weighted Approach Works
**Discovery**: Small % of records = large % of tonnage
- v1.0.0: 2.4% records = 37% tonnage (15x multiplier)
- v1.1.0: 4.4% records = 49.5% tonnage (11x multiplier)
- v1.2.0: 8.8% records = 57.3% tonnage (6.5x multiplier)

**Insight**: As we expand, the multiplier decreases (diminishing returns) but absolute tonnage still grows substantially.

### 2. Single Entities Can Have Massive Impact
**Vale Example** (v1.2.0):
- 109.6M tons across all 3 roles
- Accounted for majority of v1.2.0 tonnage gain
- Demonstrates importance of mining/commodity giants

**Implication**: Don't overlook non-oil/gas sectors - mining, aggregates, cement can be huge.

### 3. Multi-Role Entities Drive Efficiency
**Entities in All 3 Roles**:
- Chevron: 28M shipper + 59M consignee + 49M notify = 136M total
- Valero: 11M shipper + 44M consignee + 52M notify = 107M total
- Vale: 13M shipper + 44M consignee + 52M notify = 109M total

**Insight**: Large integrated companies appear in multiple roles (trading, refining, distribution). Capturing them multiplies impact.

### 4. Regional Specialization Matters
**Cement Imports**:
- v1.2.0: North American focus (Lafarge, Houston Cement)
- v1.3.0: Asian/Middle East expansion (Vietnam, Turkey, UAE)
- Combined: 19 cement entities, ~32M tons

**Insight**: Import patterns vary by region - need geographic diversity in dictionary.

### 5. Industry Depth vs Breadth
**Two Strategies**:
- **Depth**: Add more entities in same sector (cement: 19 entities)
- **Breadth**: Add new sectors (automotive, chemicals, steel)

**Balance**: v1.0.0-v1.1.0 favored depth (oil/gas), v1.2.0-v1.3.0 favored breadth (automotive, cement, trading).

### 6. Automotive Is High-Record, Medium-Tonnage
**Automotive Entities** (8 total):
- Toyota (4.2M tons), GM, Mercedes, Mazda, Kia, VW, Subaru (2.0M), Hyundai (1.9M)
- Combined: ~20M tons, but **7,000+ shipment records**
- High record count = better data quality, low tonnage = less coverage impact

**Insight**: Automotive improves record match rates more than tonnage coverage.

## Lessons Learned

### What Worked Well

1. **Tonnage-Weighted Filtering**: Focusing on high-tonnage records (≥2,500 tons) cut 93% of noise but captured 91%+ of valuable tonnage

2. **Gap Analysis Workflow**: Analyzing unmatched parties after each iteration provided data-driven entity selection

3. **Multi-Token Safety**: Using Contains_All strategy for generic names (GENERAL MOTORS not GENERAL) prevented false positives

4. **Vale Discovery**: Single entities can have massive impact - don't overlook non-oil/gas sectors

5. **Regional Diversification**: Adding Asian cement (Vietnam, Turkey) in v1.3.0 captured previously missed imports

6. **Background Processing**: Running harmonization asynchronously allowed parallel work

### What Could Be Improved

1. **Diminishing Returns**: Each iteration yields smaller coverage gains
   - v1.0.0→v1.1.0: +12.5 points
   - v1.1.0→v1.2.0: +7.8 points
   - v1.2.0→v1.3.0: +10-15 points projected

2. **Automotive Impact**: High record count but low tonnage - may not be worth the entity slots

3. **Grain Sector Neglect**: Only 2 grain entities after 3 iterations - high-impact sector still mostly uncovered

4. **Chemical Sector Gaps**: Major players (BASF, LyondellBasell) still missing despite large import volumes

5. **Output File Naming**: Harmonization script saves as "v1.0.0" regardless of dictionary version used (cosmetic issue)

### Recommendations for v1.4.0

1. **Prioritize Grain**: Add 8-10 grain traders to capture easy 6-8M tons with few entities

2. **Complete Automotive**: Add remaining 6 brands (Nissan, Honda, BMW, Ford, Stellantis, JLR) for data quality

3. **Chemical Deep Dive**: Focus on top 6 chemical companies for 8-10M ton gain

4. **Steel Finishing**: Add US Steel, Cleveland-Cliffs to complete domestic steel coverage

5. **Mining Giants**: Add Rio Tinto, BHP, Freeport-McMoRan for 5-6M tons

6. **Consider v1.5.0**: If v1.4.0 hits 75%, stop. If short, plan v1.5.0 with remaining long-tail entities.

## Technical Notes

### Dictionary Schema (10 columns)
- Entity_ID, Canonical_Name, Entity_Type, Parent_Company
- Match_Keywords, Match_Strategy, Category, Active
- Notes, Estimated_Tons

### Match Strategies
- **Contains** (85%): Substring match, safe for unique names (VALERO, CHEVRON)
- **Contains_All** (15%): Multi-token safety, requires all words (GENERAL MOTORS)

### Processing Performance
- v1.1.0: 69 entities × 449K records = ~27 minutes
- v1.2.0: 120 entities × 449K records = ~75 minutes
- v1.3.0: 163 entities × 449K records = ~60 minutes (estimated)

**Scaling**: O(n×m) where n=records, m=entities. Linear growth with entity count.
