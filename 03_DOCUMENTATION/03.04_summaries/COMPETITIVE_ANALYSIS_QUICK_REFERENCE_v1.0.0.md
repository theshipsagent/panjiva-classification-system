## Methodology Summary

**Trade Lane Definition:**
```
Origin_Port → Destination_Port | Commodity
```

**Competition Metrics:**
- **Overlap Tonnage:** MIN(Entity1_tons, Entity2_tons) per shared trade lane
- **Overlap %:** Overlap tonnage / Total entity tonnage
- **Trade Lane Count:** Number of shared origin→destination|commodity combinations

**Filtering:**
- Entity minimum: 10,000 tons
- Overlap minimum: 5% of at least one entity
- Port minimum: 5M tons total
- Commodity minimum: 100K tons total
