# 03_DOCUMENTATION - Project Documentation

All project documentation centralized in one location.

## Folder Structure

- **03.01_guides/** - Getting started and user guides
  - GETTING_STARTED.md - Quick start guide
  - DATA_DICTIONARY.md - Column definitions
  - PIPELINE_OVERVIEW.md - High-level pipeline description
  - TROUBLESHOOTING.md - Common issues and solutions

- **03.02_technical/** - Technical documentation
  - ARCHITECTURE.md - System architecture and design
  - DATA_LINEAGE.md - Data flow and transformations
  - MATCHING_ALGORITHMS.md - Matching logic details
  - NAMING_CONVENTIONS.md - File and version naming standards

- **03.03_dashboards/** - Interactive HTML dashboards
  - index.html - Main dashboard landing page
  - port_intelligence.html - Port analytics
  - classification_pipeline.html - Classification metrics
  - technical_dataflow.html - Architecture diagrams
  - assets/ - CSS, JavaScript, and data files

- **03.04_summaries/** - Analysis summaries and reports
  - PORT_CALL_MASTER_SUMMARY.md - Port call master overview
  - US_FLAG_REGISTRY_SUMMARY.md - US Flag matching results
  - FGIS_GRAIN_EXPORT_SUMMARY.md - Grain export analysis
  - VERSION_COMPARISON.md - Version history and changes

- **03.05_data_dictionaries/** - Column definition CSVs
  - PORT_CALL_MASTER_DICTIONARY.csv
  - ENTRANCE_DICTIONARY.csv
  - CLEARANCE_DICTIONARY.csv
  - CARGO_CLASSIFICATION_DICTIONARY.csv

## Usage

Open `03_DOCUMENTATION/03.03_dashboards/index.html` in a browser for the main project dashboard.

Refer to guides in 03.01_guides/ for getting started and common tasks.
